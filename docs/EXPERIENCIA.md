# Análisis de texto

Explora sentimiento, subjetividad y palabras frecuentes en texto o archivos.

- Entrada: Texto directo o archivo TXT, CSV o MD.
- Resultado: Polaridad, subjetividad, frecuencias y análisis por oración.
- Tecnología: TextBlob · Google Translate

## Uso

Elige la fuente en el panel lateral, añade el texto y pulsa Analizar texto o Analizar archivo.

## Límites

Traduce al inglés para estimar sentimiento. Ironía, contexto y errores de traducción pueden alterar el resultado.
